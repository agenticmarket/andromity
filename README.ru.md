Andromity — это терминальное рабочее пространство со встроенным ИИ-агентом. Не окно чата. Не плагин. Полноценное рабочее пространство — сессии, просмотр диффов, файловый менеджер, планировщик задач, профили — всё в вашем терминале, с ИИ-агентом, который действительно делает полезные вещи.

Отличие в одном: **ничего не запускается, пока вы не отметите папку как доверенную.**

---

## Как работает модель доверия

Когда вы открываете папку, Andromity спрашивает, доверяете ли вы ей. Этот ответ контролирует всё — ни режим прав, ни ваш API-ключ, ни настройки. Если вы скажете "нет", агент не сможет ни записать файл, ни выполнить команду, ни дотронуться до чего-либо. Точка.

Если вы ответите "да", вы сами выбираете степень свободы агента:

| Режим | Планы | Запись файлов | Shell команды |
|------|-------|-------------|----------------|
| **SAFE** | Одобрение каждого | Одобрение каждого | Одобрение каждого |
| **TRUST** | Автоматически | Напрямую — без проверки | Напрямую — без проверки |
| **FULL** | Автоматически | Напрямую | Напрямую |
| **YOLO** | Авто (показывается для информации) | В фоне | В фоне |

Начинайте с SAFE. Переходите к YOLO, когда поймете, что агент делает в вашей кодовой базе. Используйте `/trust` и `/untrust` в любое время.

## Установка

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/agenticmarket/andromity/main/install.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/agenticmarket/andromity/main/install.ps1 | iex

# Или с помощью pipx
pipx install andromity
```

Требуется Python 3.11+. Установщик сам разберется с pipx, если у вас его нет.

## Запуск

```bash
andromity
```

Это откроет рабочее пространство. Укажите папку, ответьте на запрос о доверии, выберите модель — готово. Для начала работы не нужен файл конфигурации.

```bash
# Безголовый режим / для скриптов
andromity run "добавить обработку ошибок в auth.py"
andromity run "сделать рефакторинг на async" --yes      # автоодобрение всего
andromity run "проверить session.py" --dry-run       # посмотреть, что будет сделано
```

## Что внутри

**Планировщик.** Запускайте агента по таймеру, пока спите. `/cron` открывает планировщик. Задачи сохраняются для каждого проекта в `.andromity/crons.json`. Работает в любом режиме разрешений — используйте YOLO для полностью автономной работы.

**Профили.** Переключайте задачи, которые агент пытается выполнить.
- `builder` — планирует, затем реализует
- `coder` — реализует напрямую, без этапа планирования
- `reviewer` — только чтение, выдает результаты проверки
- `planner` — только планирует, ничего не трогает

**Поддержка MCP.** Бросьте `mcp.json` в ваш проект. Инструменты загружаются лениво — сначала индексируются схемы, полные данные загружаются только тогда, когда они действительно нужны агенту. Сохраняет разумный расход токенов при 50+ подключенных инструментах.

**Сессии.** Всё сохраняется. Переключайтесь между сессиями с помощью `/sessions` или `Ctrl+O`. `/compact` когда контекст становится слишком большим. `/undo` для отмены последнего хода и всех изменений файлов.

**Звуковые уведомления.** Агент подает сигнал, когда ему требуется одобрение или он завершает свой ход. Настройте их независимо в `Ctrl+E → Advanced → Sounds`.

**Агностичность к моделям.** LiteLLM под капотом. Anthropic, OpenAI, Gemini, Groq, OpenRouter, Ollama, NVIDIA NIM. Переключайтесь в процессе сессии с помощью `Ctrl+L`.

## Конфиденциальность

Ваш код отправляется только в одно место: провайдеру LLM, которого вы настроите. Не нам.

- API-ключи хранятся в `~/.andromity/config.toml`
- Сессии хранятся локально в `~/.andromity/sessions/`
- Анонимный пинг при первом запуске — без кода, без путей, без ключей. Полная информация в [telemetry-worker/README.md](telemetry-worker/README.md)
- Чтобы отказаться: `export DO_NOT_TRACK=1`, или `telemetry = false` в конфиге, или `Ctrl+E → Advanced → Telemetry`
