### Your pull requests and issues, next to your code

**Pull Requests and Issues** lists your GitHub repository's open pull requests and issues. **For you** shows the pull requests waiting for your review, or your team's, and your own.

- **Review with Andromity** reads a pull request's description and diff and writes a review you can edit and post as a comment.
- **Ask Andromity** answers a question about any pull request or issue: what it changes, what could break, where a bug comes from.

Both open a new read-only chat. The pull request or issue is passed as text written by someone else, and the chat can read your folder but can't edit files, run commands or post anything. Merging, approving and commenting stay on GitHub.

It uses VS Code's own GitHub sign-in and works with repositories on github.com.
